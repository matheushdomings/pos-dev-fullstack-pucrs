# Pós em Desenvolvimento Full Stack — PUCRS

Repositório criado para organizar exercícios, exemplos e projetos desenvolvidos ao longo da pós-graduação em Desenvolvimento Full Stack da PUCRS.

Os conteúdos envolvem estudos de front-end, back-end, bancos de dados, cloud, DevOps e arquitetura de software.

## Conteúdos

- Fundamentos de computação e algoritmos
- Programação orientada a objetos
- DevOps básico e avançado
- Banco de dados SQL e NoSQL
- Microsserviços
- Programação web
- Arquitetura client-side e server-side
- Web services

## Tecnologias utilizadas

- JavaScript
- HTML
- CSS
- React
- Next.js
- Node.js
- Express
- NestJS
- SQL
- MongoDB
- Docker
- AWS
- Terraform
- GitHub Actions

## Repositório

Os módulos estão organizados em pastas separadas conforme o andamento da pós-graduação.
